Using an icon

Anywhere the library takes an Icon, these forms all work.

ways to name an icon
Window:AddTab({ Title = "Combat", Icon = "swords" })

Window:AddTab({ Title = "Shop", Icon = "rbxassetid://121962391563311" })

Window:AddTab({ Title = "Hub", Icon = "https://my.site/logo.svg" })

Window:AddTab({ Title = "Photo", Icon = "https://my.site/banner.png" })

Window:AddTab({ Title = "Me", Icon = "rbxthumb://type=AvatarHeadShot&id=1&w=150&h=150" })

DeaDx:RegisterIcon("brand", "https://my.site/logo.svg")
Window:AddTab({ Title = "Brand", Icon = "brand" })

Photos, and the shape of them

A photo is an icon like any other — an avatar, a decal you uploaded, a PNG on the web. It is drawn as a photo, not flattened into a theme-coloured silhouette, and you choose the corners.

square, rounded, circle
local HEAD = "rbxthumb://type=AvatarHeadShot&id=" .. me.UserId .. "&w=150&h=150"

Section:AddButton({ Title = "Square", Icon = HEAD, IconShape = "Square" })
Section:AddButton({ Title = "Rounded", Icon = HEAD, IconShape = "Rounded" })
Section:AddButton({ Title = "Circle", Icon = HEAD, IconShape = "Circle", IconSize = 34 })
Section:AddButton({ Title = "Exactly 4px", Icon = HEAD, IconCorner = 4 })

IconShape, IconCorner, IconTint, IconScale and IconSize work on every icon slot in the library — window, tab, section, card, component, status bar, notification, dialog and loading screen. The full reference is in the docs.

Roblox only draws PNG and JPG, and some hosts refuse Roblox's requests — Wikipedia answers with an HTML page, for instance. If a url fails, the console now says exactly why instead of quietly showing a question mark. GitHub raw, Imgur and most CDNs work; a Roblox decal via rbxassetid:// always works and needs no download at all.
Catalog names resolve to a Roblox asset id with no download at all. Only URLs and custom providers touch the network, and those are cached to disk after the first run.

Where to find more icons

The catalog is the Lucide set. For anything outside it, grab an SVG or PNG URL from one of these and feed it to RegisterIcon — DeaDx parses the SVG, rasterises it and caches the result.

Lucide

The set that ships inside DeaDx. Copy the icon name straight from the site — if it exists in Lucide, it is almost certainly in the catalog above.

Iconsax

Linear, bold, broken and bulk weights. Register it as a provider once and you can reference the whole set by name, same as the catalog.

Roblox Creator Store

Any decal or image asset you own. Pass rbxassetid://ID and it renders with no caching layer involved at all.

Simple Icons

Brand marks — Discord, YouTube, GitHub. Single-path SVGs, which is exactly what the parser handles best.

How the cache works

Icons that come from a URL are written to the executor's workspace once and verified by content on every later run.

DeaDx/icons/
DeaDx/icons/
├── index.json       name → hash, size, when it was fetched
├── rocket.svg       the file itself
├── rocket.json      parsed geometry, ready to draw
├── logo.svg
└── logo.json
  1. First run — downloads the file, parses it, writes name.svg, name.json and a hash into index.json.
  2. Later runs — reads the local file and draws it. Measured at about 1 ms.
  3. Verification — in the background, the source is re-hashed. If the content changed, the file is overwritten and IconStore.Updated fires so your UI can refresh.
  4. Unchanged — nothing is written and nothing re-downloads.
cache control
DeaDx:SetIconVerify(true)

local stats = DeaDx:GetIconStats()
print(stats.Cached, stats.Hits, stats.Misses, stats.Bytes)

DeaDx:ForgetIcon("logo")
DeaDx:ClearIconCache()

DeaDx.IconStore.Updated:Connect(function(name)
    print(name .. " changed on the server, cache refreshed")
end)
